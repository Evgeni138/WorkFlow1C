# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое 1C AI Development Kit?

Это комплексный набор инструментов для эффективной разработки на платформе 1С:Предприятие с использованием AI-ассистентов. Включает навыки (skills), правила и MCP-серверы. Работает в **opencode** (производная от [1c-ai-development-kit](https://github.com/Arman-Kudaibergenov/1c-ai-development-kit)).

### Нужна ли подписка для использования?

Базовый набор (агенты, навыки, правила) — **бесплатный**. Некоторые MCP-серверы платные, но можно использовать и без них.

### Какие версии 1С поддерживаются?

1С:Предприятие 8.3 (все редакции: базовая, КОРП, УТ, ERP и т.д.)

### Работает ли с EDT (Eclipse Development Tools)?

Пока нет, но в планах. Сейчас поддерживается opencode.

## Установка и настройка

### Как установить базовый набор?

Скопируйте/склонируйте шаблон в ваш проект (или разверните его поверх существующего проекта 1С):

```bash
git clone https://github.com/<you>/<template-repo>.git
cd <template-repo>
```

Затем заполните `.v8-project.json`, настройте `opencode.jsonc` и запустите opencode.

См. [Руководство по установке](guides/installation.md)

### Нужно ли устанавливать все MCP-серверы?

Нет. Начните с бесплатных (`rlm-tools-bsl`, `bsl-language-server`, `v8std`), остальные добавьте по необходимости.

### Как получить доступ к платным MCP?

Платные MCP-серверы можно приобрести на [vibecoding1c.ru/mcp_server](https://vibecoding1c.ru/mcp_server)

**Что вы получаете:**
- Docker-контейнеры для развертывания на вашем сервере
- Инструкции по настройке и запуску
- Доступ к обновлениям
- Поддержку в сообществе

**Что входит:**
1. HelpSearchServer — поиск по справке 1С (RAG)
2. Graph Metadata Search — графовый поиск по метаданным
3. CodeMetadataSearchServer — поиск по коду и метаданным
4. SSLSearchServer — справка по БСП
5. SyntaxCheckServer — проверка синтаксиса (BSL LS)
6. TemplatesSearchServer — библиотека шаблонов
7. 1CCodeChecker — проверка через 1С:Напарник (требует ваш ключ)
8. FormsServer — работа с формами

**Важно:**
- ✅ Вы разворачиваете на своем сервере (не SaaS)
- ✅ Все данные остаются у вас
- ✅ Используете свои API-ключи (OpenAI, 1С:Напарник и т.д.)
- ✅ Полный контроль над инфраструктурой
- ✅ Можете использовать локальные модели (LMStudio, Ollama)

**Автор:** Олег Филиппов ([@comol_foa](https://t.me/comol_foa))  
**Сообщество:** [t.me/comol_it_does_matter](https://t.me/comol_it_does_matter)

### Можно ли использовать без MCP-серверов?

Да! Агенты, навыки и правила работают и без MCP. MCP-серверы — это дополнительные возможности.

## Использование

### Как запустить агента?

В opencode:
1. Откройте чат
2. Напишите задачу, например: "Проверь код модуля X"
3. AI автоматически выберет подходящий навык (skill)

Или явно: "Используй skill inspect для проверки модуля X"

### Как использовать навык?

Навыки используются автоматически, когда AI определяет подходящую задачу. Или явно:

```
Пользователь: Используй навык 1c-forms/compile для создания формы
```

### Какой агент выбрать для задачи?

В этом шаблоне вместо агентов используются **skills** (вызываются явно или автоматически). См. таблицу в [README.md](../README.md).

### Как сэкономить токены?

1. Используйте `rlm-tools-bsl` для экономии контекста при анализе кода
2. Запускайте агентов параллельно (изолированный контекст)
3. Начинайте новый чат при достижении 100k токенов
4. Используйте Sonnet 4.5 для рутинных задач, Opus 4.6 только для критичных

Выбор модели и экономии токенов настраивается в opencode (модели, API-ключи).

## Проектные MCP

### Зачем нужны проектные MCP?

Они индексируют вашу конфигурацию и позволяют AI:
- Искать по метаданным и коду семантически
- Строить граф зависимостей
- Отвечать на вопросы о вашем проекте

### Сколько стоит создать проектный MCP?

**Облачная индексация:**
- Малая конфигурация (<10k строк): $0.10-0.20
- Средняя (10-50k): $0.50-1.00
- Большая (50-200k): $1.00-2.00

**Локальная индексация:** бесплатно, но требует времени (часы)

### Как часто нужно переиндексировать?

При изменении конфигурации. Можно настроить автоматическую переиндексацию через Git hook.

### Можно ли использовать без GPU?

Да, но медленнее. Рекомендуется GPU для локальной индексации.

## Проблемы

### Агенты не работают

**Проверьте:**
1. opencode установлен и запущен в корне проекта
2. Файлы навыков в `.claude/skills/` и `.opencode/skills/` на месте
3. Перезапустите opencode после изменений

См. [Руководство по установке](guides/installation.md)

### Проблемы с MCP-серверами

**Проверьте:**
1. Сервер запущен: `curl http://localhost:PORT/health`
2. Пути в `opencode.jsonc` (`{{AI_ENV}}`, `{{WORKSPACE_ROOT}}`) корректны
3. У `bsl-language-server` корень `-s` = `{{WORKSPACE_ROOT}}\external` (не корень проекта!) — если `-s` указывает на весь workspace, bsl-analyzer долго индексирует конфигурацию 1С из `src/`/`ext/`; полная выгрузка анализируется через `rlm-tools-bsl`
4. Логи сервера

### Навыки не выполняются

**Проверьте:**
1. Файлы `SKILL.md` на месте
2. Права выполнения для скриптов (`.ps1`, `.bat`)
3. Попросите AI явно: "Используй навык X"

### AI не следует стандартам кодирования

**Проверьте:**
1. Файл `AGENTS.md` на месте и подключён в `opencode.jsonc` как instructions
2. Правила не переопределены в других файлах
3. Попросите AI явно: "Следуй стандартам из AGENTS.md"

### Ошибка "Token limit exceeded"

**Решение:**
1. Начните новый чат
2. Используйте `rlm-tools-bsl` для экономии контекста
3. Запускайте агентов для изоляции контекста

## Разработка

### Как создать свой навык?

1. Изучите существующие навыки в `.claude/skills/`
2. Создайте папку `your-skill/`
3. Создайте `SKILL.md` по образцу существующих
4. Добавьте скрипты в `scripts/`
5. Протестируйте

См. [Создание навыков](guides/custom-skills.md)

### Как создать своего агента?

В этом шаблоне агенты заменены skills — модульными инструкциями для AI. Чтобы расширить
функциональность, добавьте новый skill (см. ниже).

См. [Создание навыков](guides/custom-skills.md)

### Как добавить новое правило?

1. Создайте файл правил или дополните `AGENTS.md`
2. Опишите роль, ответственности, инструменты
3. Добавьте примеры и критические правила
4. Перезапустите opencode

## Производительность

### Сколько токенов потребляет типичная задача?

| Задача | Токены (примерно) |
|--------|-------------------|
| Простой вопрос | 1-5k |
| Код-ревью модуля | 10-30k |
| Генерация формы | 5-15k |
| Архитектурное решение | 20-50k |
| Полный цикл разработки | 50-200k |

### Как ускорить работу AI?

1. Используйте агентов (параллельно)
2. Начинайте новый чат при 100k+ токенов
3. Используйте `rlm-tools-bsl` для кэширования
4. Используйте Sonnet 4.5 (быстрее Opus 4.6)

### Сколько стоит использование?

Зависит от модели и объёма. Стоимость определяется тарифами провайдера модели (API opencode/вашей модели).

**Типичные затраты:**
- Лёгкое использование: $20-40/мес
- Среднее использование: $40-80/мес
- Интенсивное использование: $80-150/мес

## Безопасность

### Безопасно ли отправлять код в MCP?

**Бесплатные MCP (локальные):** Да, код не покидает вашу сеть

**Платные MCP (облачные):** Зависит от провайдера. Уточните политику конфиденциальности.

**Проектные MCP:** Вы контролируете, где хранятся данные (локально или в облаке)

### Как защитить credentials?

1. Добавьте в `.gitignore`: `*.env`, `.v8-project.json`
2. Используйте переменные окружения
3. Не коммитьте файлы с паролями
