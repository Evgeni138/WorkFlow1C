# src/ — выгрузка главной конфигурации

Сюда выгружается основная конфигурация 1С (DumpConfigToFiles / db-dump-xml).
После выгрузки выполняется RLM-индексация (`rlm_index build`) и адаптация `AGENTS.md`.

При деплое шаблона содержимое этого каталога появляется автоматически — не выкладывай
выгрузку в git, если не планируешь хранить её в этом репозитории.
